## Q2. Автообновление модуля

**Коротко:** Флаг «Автоматически обновлять модуль» находится в «Настройки → Расширенные настройки → Системные», включён по умолчанию; на тарифе «Стартовый» его нельзя отключить. Автообновление недоступно на устаревшей/неподдерживаемой конфигурации и при запуске из обработок конфигурации. Для доработанного модуля используется кнопка «Оставить заявку на подключение» (обновление через поддержку). Достоверность: подтверждено офиц. (частично — политика для доработанного модуля только в гайде).
