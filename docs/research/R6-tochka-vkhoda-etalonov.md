# R6. Точка входа для эталонных XML (ТЗ-2): как сформировать пакет без отправки

> Версия: 1.0 · 07.10.2026 · Исследование по коду `SRC/TypeDiadok` (без запуска 1С). Закрывает работу 2.1 ТЗ-2 по коду; подтвердить на базе.

## Коротко

Использовать **документированный API подключаемого модуля** (`КонтурДиадокВызовыПМ`), а не внутренние функции Ядра: API вендор меняет реже.

| Случай ТЗ-2 | Функция вендора | Что возвращает |
|---|---|---|
| X2, X3, X4, X5 (исходящие) | `ЭДО_ПодготовитьПакетКОтправке(СтрокаСписка)` → внутри `Ядро.Пакеты_ПодготовитьПакет(СтрокаСписка, Ложь)` | Пакет со всеми документами, параметрами отправки, печатными формами — **без отправки**. Вызывает событие ПМ `ПослеПодготовкиПакета` |
| Получение `СтрокаСписка` по документу 1С | `ЭДО_Модуль_ОбновитьСписокДокументов(ПараметрыОбновленияСписка)` в режиме «пакеты на отправку» с отбором по документу 1С (`ОтборПоДокументу1С` — параметр контракта, наша поз. 10) | Строки списка пакетов на отправку |
| X1 (входящий УПД) | `ЭДО_ПолучитьСтруктурированныйКонтентВходящегоДокумента(ДокументЭДО)`; для сопоставления — `ЭДО_ПровестиАнализВходящегоДокумента(ДокументЭДО)` | Разобранный контент: строки, номенклатура, единицы |
| X6 (хранение в прикреплённых файлах) | Запись — через отправку не нужна; чтение — `ЭДО_ПолучитьДанныеДляСохраненияДокументооборота(ДокументДД)` / архив документооборота | Данные из нашего хранилища |

## Как получить объект API в обработке эталонов

Тот же объект, что вендор передаёт в наш ПМ как `ОсновнойМодуль`. Варианты (выбрать на базе в ТЗ-0):
1. Внутри нашего ПМ (он получает `ОсновнойМодуль`) — добавить служебную команду «Сформировать эталоны» (только для тестовой базы).
2. Во внешней обработке: `Обработки.КонтурДиадокВызовыПМ.Создать()` и инициализация как в `КонтурЭДО` (⚠️ требует изучения инициализации — у объекта есть переменная `Ядро`, позиция 4 делает её экспортной).

**Рекомендация ИИ:** вариант 1 — служебная команда в ПМ, видимая только в тестовой базе. Не требует знать внутреннюю инициализацию вендора.

## Что сохранять в эталон

| Поле | Откуда |
|---|---|
| XML содержимого каждого документа пакета | `Пакет.Документы[i]` — контент |
| `ЗапрашиватьОтветнуюПодпись` | параметры документа в пакете |
| Формат отправки, состав печатных форм, имя файла | `ПараметрыОтправкиВидаДокумента`, документы пакета |
| Прочитанные настройки по договору | результат чтения настроек (X2/X3) |

Маскировать: GUID, дату/время формирования, имена файлов с датой.
