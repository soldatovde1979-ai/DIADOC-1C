## Глоссарий

| Термин | Что это |
|---|---|
| **Расширение (AddOn)** | Надстройка над конфигурацией 1С, файл `.cfe`. Модуль Диадок вендор поставляет именно так. |
| **ПМ, подключаемый модуль** | Наша обработка `ДД_подключаемыйМодуль`. Вендор вызывает её в официальных событиях (`ПодготовитьПакет` и др.). |
| **Местонахождение ПМ** | Настройка модуля Диадок: где искать ПМ — «Конфигурация», «Диск» или «1С» (справочник доп. обработок). |
| **Пакетный режим Конфигуратора** | Запуск `1cv8.exe DESIGNER …` с ключами, без окон: выгрузка, загрузка, проверка модулей. |
| **Служебная ИБ** | Пустая файловая ИБ на УТ11 для выгрузки чистого дистрибутива и проверок. В проде не используется. |

## 3. Сценарии проверки (человек, на служебной/тестовой ИБ)

> Ключи Конфигуратора указаны **по памяти** — сверить со справкой установленной версии платформы (`1cv8.exe /?`, ИТС «Пакетный режим»).
> ОС: Windows, оболочка PowerShell. Выполнять **на тестовой машине**, не на проде. Проверить: `$env:COMPUTERNAME`.

**С1 (Г1). ПМ из основной конфигурации.**
1. В тестовой ИБ создать в основной конфигурации обработку `ДД_подключаемыйМодуль_Тест` с текстом модуля текущего ПМ.
2. В настройках Диадок: «Местонахождение подключаемого модуля» = «Конфигурация», имя — `ДД_подключаемыйМодуль_Тест`.
3. Открыть модуль Диадок, подготовить пакет по документу, у которого срабатывает поз. 1 (запрос подписи по договору).
4. Результат: событие отработало (видно по флажку «Запросить подпись контрагента»).

**С2 (Г2).** Добавить в основную конфигурацию общий модуль `т1кДиадокФормы` (сервер) с процедурой `Тест() Экспорт`,
вызвать его из `ПриСозданииНаСервере` формы `ФормаУправляемая` расширения. Проверить модули расширения — без ошибок.

**С3 (Г3).** На копии тестовой ИБ загрузить полный `TypeDiadok` как `.cfe` вместо текущего расширения.
Открыть модуль, пройти первичную настройку, загрузить список документов. Посмотреть журнал регистрации на ошибки.

**С4 (Г4).** В `т1кДиадокФормы` реализовать `ПриСозданииНаСервере(Форма)`: добавить реквизит `шхТест` (Булево),
элемент-флажок в группу, которая есть на форме, `УстановитьДействие("ПриИзменении", "Подключаемый_ШхПриИзменении")`.
В модуле формы — клиентская процедура `Подключаемый_ШхПриИзменении(Элемент)`, вызывающая клиентский общий модуль.
Проверка: флажок виден, обработчик срабатывает, значение не теряется при серверном вызове.

**С5 (Г5).** Найти в настройках модуля управление автообновлением (или в `ОбновлениеМодуля_*` — что его включает).
Описать, как выключить и как проверить, что выключено.

**С6.** Проверить запрет заимствования объектов чужого расширения: создать пустое расширение и попробовать
заимствовать `Обработка.КонтурЭДО`. Ожидание: объект недоступен для заимствования. Нужно только для фиксации факта.

**С7 (Г6).** Проверить команды (⚠️ по памяти):
```
1cv8.exe DESIGNER /F "<путь_к_ИБ>" /N "<пользователь>" /P "<пароль>" /DumpConfigToFiles "<каталог>" -Extension КонтурДиадок
1cv8.exe DESIGNER /F ... /LoadConfigFromFiles "<каталог>" -Extension КонтурДиадок
1cv8.exe DESIGNER /F ... /LoadCfg "<файл.cfe>" -Extension КонтурДиадок
1cv8.exe DESIGNER /F ... /UpdateDBCfg -Extension КонтурДиадок
1cv8.exe DESIGNER /F ... /CheckModules -ThinClient -Server -Extension КонтурДиадок
1cv8.exe DESIGNER /F ... /DumpCfg "<файл.cfe>" -Extension КонтурДиадок
... /Out "<лог.txt>" /DisableStartupDialogs
```
Разбор:
- `DESIGNER` — режим Конфигуратора.
- `/F` — путь к файловой ИБ, `/N`, `/P` — пользователь и пароль. Пароль не хранить в скриптах — только переменная окружения.
- `/DumpConfigToFiles` — выгрузка в XML.
- `/LoadConfigFromFiles` — загрузка из XML. **Перезаписывает расширение в ИБ.**
- `/LoadCfg` — загрузка `.cfe`. **Перезаписывает.**
- `/UpdateDBCfg` — применение к БД. **Необратимо без бэкапа.**
- `/CheckModules` — синтаксическая проверка для указанных контекстов.
- `/DumpCfg` — сборка файла `.cfe`.
- `-Extension` — действие относится к расширению.
- `/Out` — лог.
- `/DisableStartupDialogs` — без диалогов.

Отдельно: нужен ли `ConfigDumpInfo.xml` при полной загрузке (ожидание: нет).

**С8.** Узнать у автора или по истории, зачем режим совместимости расширения поднят до 8.3.17 (Ф8).
Проверить, что полный дистрибутив с режимом 8.3.17 загружается.

**С9 (Г7).** По документации вендора (developer.kontur.ru, раздел ПМ) и макету событий выяснить параметры событий
`ПодготовитьЭлектронныйДокумент`, `ПровестиАнализДокумента`, `ПослеАнализаПакета`. Можно ли в них заполнить
единицу измерения строк (поз. 7) и параметры отправки (поз. 12)? ИИ готовит выписку, человек подтверждает на ИБ.

**С10 (Г8).** Как сейчас попадают в основную конфигурацию объекты `т1к*`: вручную в Конфигураторе или загрузкой из файлов?
Стоит ли основная конфигурация на поддержке? Ответ определяет способ доставки модулей Шага 3.

**С11. Ретро-данные.** Какие версии вендора вышли после 4.61.1? Есть ли их `.cfe`? Нужны для ретро-прогона (TZ-1 §3.4).
