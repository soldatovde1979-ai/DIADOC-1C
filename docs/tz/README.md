# ТЗ к плану v4: индекс

> Версия: 4.0 · 09.10.2026 · К [плану v4](../plan.md). Номер ТЗ = номер шага плана (my-FT Р-5). Комплект v3 — [docs/archive/v3/tz/](../archive/v3/tz/README.md).

## С какими документами работаем

| Документ | Что в нём | Когда открывать |
|---|---|---|
| [План](../plan.md) | что делаем и почему, шаги 0–8, трудозатраты, термины (§9) | сначала |
| [Реестр изменений](../Диадок_РеестрИзменений.md) | **что и как** меняем по каждой из 26 доработок; таблица зацепок; объекты и данные вне позиций | при работе с любой доработкой |
| ТЗ-0…ТЗ-8 (ниже) | **как** выполнить шаг: вход, работы, выход, приёмка, вопросы | при выполнении шага |
| [my-FT](../my-FT.md) | требования со слов пользователя | при сомнении «а так ли надо» |

## Устройство каждого ТЗ

Шапка (пункт плана, зависимости, кто делает, позиции, статус) → 1. Зачем → 2. Вход → 3. Что сделать → 4. Выход → 5. Критерии приёмки → 6. Чего шаг не делает → 7. Вопросы.

У каждого раздела в скобках указан пункт плана, к которому он относится: **[План: шаг N, «Что делаем»]**. Термины не повторяются — они объяснены в плане (§9), так один факт живёт в одном месте (my-FT Р-9).

Открытые вопросы — в конце каждого ТЗ, с действием «что делаем, пока нет ответа». Работу они не блокируют.
