# Индекс ТЗ по плану автоматизации обновления модуля Контур.Диадок

> Часть 2 плана ([docs/plan.md](../plan.md)). Каждому шагу плана соответствует один документ ТЗ в этой папке.
> Единая структура ТЗ: Глоссарий → 1. Что разработать → 2. Как использовать → 3. Входы/выходы и работы → 4. Критерии приёмки → 5. Связка с реестром.
> Каждое ТЗ имеет поле «Кто делает» — распределение работы между ИИ и человеком.
