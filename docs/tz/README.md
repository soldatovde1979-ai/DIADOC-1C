# Индекс ТЗ по плану автоматизации обновления модуля Контур.Диадок

> Версия: 3.0 · 07.10.2026. Часть 2 плана ([docs/plan.md](../plan.md) v3). Каждому шагу плана соответствует один документ ТЗ с тем же номером.
> Единая структура ТЗ: шапка (пункт плана, зависимости, кто делает, позиции реестра, статус) → Глоссарий («что это простыми словами») →
> 1. Зачем это и что делаем → 2. Что разработать → 3. Как использовать → 4. Входы/выходы → 5. Работы → 6. Критерии приёмки →
> 7. Что не делает этот шаг → 8. Связка с реестром.
> Каждое ТЗ имеет поле «Кто делает» — распределение работы между ИИ и человеком.
