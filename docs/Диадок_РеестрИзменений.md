# Реестр кастомизаций модуля Контур.Диадок (ТЗ на вынос изменений)

- Версия: 3.0 · 07.10.2026 (изменения относительно предыдущих версий — в конце документа).
- База сравнения: чистый дистрибутив вендора `SRC/TypeDiadok` (версия 4.61.1, `Configuration.xml`).
- Текущее состояние: корень проекта — расширение конфигурации (AddOn) `КонтурДиадок` 4.61.1 + правки внутри модулей, помеченные маркером `ШХ`.
  **Это расширение — поставка вендора**: при обновлении оно заменяется целиком (ТЗ-0, Ф1).
- Часть нашей логики уже живёт в основной конфигурации УТ11: `т1кДиадокСервер`, `т1кСверкаОказанныхУслуг`, регистры `т1кДиадок_НастройкиДоговоров`, `т1кЗначенияПроизвольныхПараметров` (ТЗ-0, Ф3).
- В чистом дистрибутиве маркер `ШХ` не встречается ни разу (проверено поиском по `*.bsl`) — вся дельта однозначно наша.
- Объём дельты (проверено 07.10.2026): 12 вендорских файлов, ≈167 мест, +2690/−111 строк; строк с маркером `ШХ` — 222 в 13 файлах.
- План работ — [docs/plan.md](plan.md), ТЗ — [docs/tz/](tz/README.md).
- Статус: **НА СОГЛАСОВАНИИ**.

## Действия-сокращения (легенда колонки «Действие с кодом»)

- **Перенос ПМ в основную конфигурацию** — наш подключаемый модуль переезжает из расширения вендора в основную конфигурацию УТ11 как есть. Обновление вендора его больше не трогает.
- **Вынос в наш модуль + точка вызова** — тело нашей процедуры переезжает в общий модуль основной конфигурации (`т1кДиадокМодули`); в коде вендора остаётся 1–2 строки вызова с меткой ШХ.
- **Форма — программно** — наши реквизиты, элементы, команды и обработчики создаёт код (`т1кДиадокФормы`) при открытии формы. Файл формы вендора не меняется; в модуле формы — типовой переходник и вызовы с меткой ШХ.
- **Точка вызова** — вставка в код вендора сводится к одному вызову нашего модуля.
- **Встроенная дельта** — то, что вынести нельзя (новый параметр функции, изменённое выражение). Остаётся в коде вендора минимально, с меткой ШХ; на новую версию переносится слиянием git.
- **Метаданные расширения** — объекты/свойства расширения (роль, режим совместимости), переносятся слиянием git.
