# Набор для Шага 0 (ТЗ-0): проверка осуществимости на тестовой базе

> Версия: 1.0 · 07.10.2026 · Где: **тестовая машина, тестовая база** (проверить: PowerShell → `$env:COMPUTERNAME`). Прод не трогаем — кроме пункта «Срочно», там только **смотрим**.
> Результаты — в таблицу ТЗ-0 §6. Все тестовые объекты после проверки удалить из тестовой базы.

## Срочно, до всего остального (5 минут, прод, только посмотреть)

Модуль Диадок → Настройки → группа «Автоматическое обновление» → **«Автоматически обновлять модуль» должно быть выключено.**
Почему: позиция 11 отключила защиту вендора от обновления доработанного модуля ([R4](../../docs/research/R4-avtoobnovlenie-i-poz11.md)). Если галочка включена — вендор может сам поставить чистую версию и стереть все наши доработки. Заодно посмотреть журнал регистрации: события `УспешноеАвтообновлениеМодуля` / `ОшибкаАвтообновленияМодуля`.

## С4 — что отметить (каждый пункт отдельно: да / нет)

| | Проверка | Как увидеть |
|---|---|---|
| а | Реквизит добавлен кодом | Флажок «Тест ШХ (С4)» есть на форме |
| б | Элемент в группе вендора | Флажок стоит в «ГруппаФильтров», рядом с «Режим подписания» |
| в | Обработчик элемента назначен кодом | Щелчок по флажку → сообщение «С4: сработал обработчик элемента…» |
| г | Событие формы назначено кодом | Закрыть и снова открыть форму (повторное открытие) → «С4: сработало событие формы…» |
| д | Команда и кнопка созданы кодом | Кнопка «Тест ШХ (С4)» в командной панели → «С4: сработала команда…» |
| е | Значение не теряется на сервере | В сообщении из «в» значения «на клиенте» и «на сервере» совпадают |

Хотя бы один пункт «нет» → для этой формы действует запасной вариант Г4 (вставки в модуле формы — встроенная дельта), план не ломается.

Уже есть подтверждение из прода: наша вставка в `ФормаУправляемая` создаёт команду и кнопку «Отклонить» кодом (`ФормыУХ.СоздатьКнопкуФормы`, строки ~596–604) — пункт «д» фактически работает.
